# Siddhj2206 Tap

## How do I install these formulae?

`brew install siddhj2206/tap/<formula>`

Or `brew tap siddhj2206/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "siddhj2206/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
